# 이전 검증과 현재 방향까지의 학습

## 1. 처음 문제: 흩어진 자취 정보

자취 생활에서 정보가 없어서 시간과 돈을 낭비했던 개인 경험으로 시작했습니다. 초기에는 주거지원, 청소, 수리 등 흩어진 정보를 모아서 제공하는 `자취 정보 조립소`를 생각했습니다.

인스타그램 광고를 3일간 집행해 다음 결과를 얻었습니다.

- 광고비 16,047원
- 광고 관리자 기준 CTR 2.58%
- 광고 유입자의 카드 열람률 4%
- 유입자의 58%가 3초 이내 이탈
- 지인 유입 카드 열람률 27%

당시에는 문제 소재에는 관심이 있지만, 정보를 길게 펼쳐 읽는 형식과 다시 방문할 이유가 약하다고 해석했습니다.

## 2. 두 번째 방향: 청소·관리 루틴

재방문을 만들기 위해 청소·관리 주기와 알림을 제공하는 방향을 검토했습니다. 그러나 조사 과정에서 청소를 미루는 핵심 이유가 주기를 몰라서라기보다 귀찮음에 가깝고, 알림 그 자체보다 **놓쳤을 때 실제 손실이 큰 순간**에 관심이 더 크다고 보았습니다.

## 3. 계약 전 주거지원 조건 확인 프로토타입

다음으로 사용자의 개인 조건과 실제 매물 조건을 함께 입력하면 확인할 주거지원과 후속 행동을 안내하는 프로토타입을 만들었습니다.

사용자는 다음을 입력했습니다.

- 개인 조건: 연령, 무주택 여부, 소득 확인 여부, 기존 주거지원 수혜 이력
- 매물 조건: 지역, 보증금, 월세, 주택 유형, 전입신고 가능 여부
- 증빙 조건: 계약서, 월세 납부 기록, 중개보수·이사비 영수증

프로토타입은 다음을 제공했습니다.

- 확인할 주거지원과 현재 조건에 맞지 않을 수 있는 이유
- 계약 전에 추가로 확인할 매물 조건
- 공인중개사·임대인에게 물어볼 질문
- 계약·입주 과정에서 보관할 서류와 기록
- 최종 조건을 확인할 공식 출처

## 4. 외부 사용자 13명 결과

- 13명 모두 하나 이상의 새로운 주거지원을 발견했습니다.
- 이자지원, 중개보수, 이사비 지원은 각각 12명이 새롭게 확인했습니다.
- 복지로 청년월세 지원과 다른 기관 월세지원의 순차 신청 가능성은 8명이 새롭게 확인했습니다.
- 월세 납부 기록 11명, 현재·과거 수혜 이력 10명, 중개보수·이사비 영수증 8명, 주택 형태와 건축물대장상 용도 7명에게 새로운 확인 필요가 생겼습니다.
- 전입신고, 확정일자, 건축물대장상 용도, 계약서·입실확인서, 월세 납부 증빙 등에 관해 다수에게 새로운 질문이 생겼습니다.
- 13명 중 5명이 선택 문항인 베타 출시 연락처를 남겼습니다.

### 이 결과가 말해주는 것

- 개인 조건과 매물 조건을 연결하면 사용자가 몰랐던 정보와 다음 질문을 발견할 수 있습니다.
- 단순한 지원금 목록보다 `왜 추가 확인이 필요한지`와 `누구에게 무엇을 물을지`가 가치가 있습니다.
- 실제 매물을 입력하게 하는 방식은 일반적인 사용 의향 설문보다 행동 신호가 강합니다.

### 아직 말해주지 못하는 것

- 사용자가 실제 집보기 현장에서 서비스를 켜는지
- 중개사가 옆에 있는 상황에서도 5분 안에 기록할 수 있는지
- 두 번째·세 번째 매물에서도 반복 사용하는지
- 비교 결과가 추가 질문, 재방문, 후보 제외, 계약 판단으로 이어지는지
- 연락처를 남긴 사용자가 실제 베타에 참여하는지
- `플랫폼 중립·임차인 우선` 포지셔닝이 선택 이유가 되는지

표본은 13명으로 작고, 사용 직후 30초 자기보고 설문이 중심이었습니다. 따라서 이 결과는 현재 제품 전체의 수요가 아니라 **조건형 안내가 새로운 정보와 행동 후보를 만든다는 초기 증거**로만 사용합니다.

## 5. 현재 방향으로 이어진 해석

주거지원 프로토타입에서 가치가 컸던 것은 정책 목록 자체보다 다음 구조였습니다.

```
나의 조건 + 후보 집의 조건
→ 지금 확인하지 않은 것 발견
→ 구체적인 질문과 기록 생성
→ 공식 출처에서 최종 확인
```

이 구조를 집보기 전체로 확장합니다.

```
후보 매물 + 상황별 체크
→ 직접 본 상태와 답변 기록
→ 후보 간 동일 기준 비교
→ 계약 전 다음 행동 결정
```

주거지원은 사라지는 기능이 아니라 방문 전·계약 전 단계에서 확인할 하나의 모듈로 남습니다. 다만 현재 핵심 검증은 `지원금을 새로 알게 되는가`에서 `현장에서 반복 사용하고 비교 판단에 활용하는가`로 이동했습니다.
