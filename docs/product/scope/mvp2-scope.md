# MVP2 범위

- 상태: 구현 기준 v1

## 목표

MVP2는 완벽한 운영 제품보다 [와이어프레임](../../design/wireframes/README.md)의 전체 흐름을 로컬에서 직접 사용해보고 빠르게 수정할 수 있는 완성본을 우선합니다. 정책이 비차단적이면 구현자가 결정하고 [결정 대장](../decisions/README.md)에 남깁니다.

## 포함

### MVP1 완성·화면 개편

- Google 로그인과 로컬 전용 데모 로그인
- 매물 목록·등록·상세·수정·삭제
- 주소 검색 또는 지도 선택으로 매물 위치 입력
- 실제 사진 업로드·조회·삭제와 대표 사진 지정
- 기본 메모 양식과 자유 메모
- 시스템·사용자 체크리스트 관리
- 매물 단계별 체크리스트 적용·교체·상태·메모 자동 저장
- 전체·단계별 진행 현황과 최근 활동 정렬
- 매물 비교용 CSV 다운로드
- 마이페이지·로그아웃과 모든 정상·빈·로딩·오류 상태

### 지도

- 현재 위치와 위치 권한 거부 대체 경로
- 기존 좌표 보유 매물 핀
- 지도 중심 이동과 선택 위치의 도로명·지번 주소 확인
- 선택 위치를 매물 등록 화면으로 전달
- 병원·교통·학교·편의점·중개업소 카테고리
- 500m·1km·2km 주변 시설 조회와 집계
- 외부 API 키가 없을 때 동일 화면을 확인하는 데모 데이터
- 키가 있을 때 Kakao Maps JavaScript SDK와 Kakao Local REST API 사용

### 개발·배포 준비

- MySQL·MinIO 기반 로컬 실행
- 운영에서 S3 사진 저장
- `demo`와 `live` 외부 연동 모드
- OpenAPI·Swagger와 환경변수 예시
- 단일 EC2·Caddy·로컬 MySQL 배포 준비 문서와 수동 배포 워크플로

## 제외

- 사용자 간 체크리스트 공유와 공개 리뷰
- 사용자가 임의 문구의 새 체크 질문을 만드는 기능
- 체크 기록 리비전·교체 전 이력 복구
- 매물 추천·점수·자동 판정
- 실시간 버스 도착·교통 혼잡 분석
- 주변 시설 데이터를 자체 DB에 장기 저장하는 수집 시스템
- 사진 순서 드래그 변경
- 관리자 화면, 회원 탈퇴, 삭제 데이터 복구
- 결제·과금 API 자동 활성화
- 이번 구현 작업 중 실제 AWS 리소스 생성과 외부 배포

## 완료 기준

- `demo` 모드에서 외부 계정이나 키 없이 전체 화면과 주요 흐름을 로컬에서 실행합니다.
- `live` 모드의 키를 설정하면 실제 Google 로그인, Kakao 지도·주소·주변 시설, S3 사진 저장으로 전환할 수 있습니다.
- 17개 기준 화면과 7개 빈 상태를 모바일 폭에서 탐색할 수 있습니다.
- CRUD와 체크 자동 저장 결과가 MySQL에 남습니다.
- MVP1 핵심 소유자 검증과 스냅샷 정책을 유지합니다.
- 백엔드 테스트·프론트엔드 테스트·빌드와 대표 브라우저 흐름이 통과합니다.
- 구현 중 새로 내린 비차단 결정이 결정 대장과 관련 명세에 반영됩니다.
- 실제 배포에 필요한 사용자 설정과 남은 작업을 문서만 보고 확인할 수 있습니다.
