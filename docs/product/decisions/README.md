# MVP2 제품·구현 결정 대장

- 상태: 구현 기준 v1

## 사용 방법

MVP2는 빠르게 실행 가능한 결과를 우선합니다. 비차단적인 모호함은 아래 기본 결정을 따르고 구현 중 새 결정은 다음 번호로 추가합니다. 사용자가 결과를 사용한 뒤 방향을 바꾸면 기존 행을 지우지 않고 상태를 `대체됨`으로 바꾼 뒤 새 결정을 추가합니다.

## 구현 중 멈춰야 하는 경우

다음은 비차단 결정으로 처리하지 않습니다.

- 결제·과금 또는 유료 API 활성화
- 실제 AWS 자원 생성·도메인 연결·외부 배포
- 개인정보 처리 범위를 넓히는 기능
- 복구하기 어려운 데이터 삭제나 저장소 이력 재작성

그 밖의 UI 세부값·오류 문구·기술 구현 선택은 구현자가 진행하고 이 대장에 기록합니다.
