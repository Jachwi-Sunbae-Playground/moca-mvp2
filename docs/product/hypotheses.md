# 핵심 가설

> 이 문서는 살아있는 문서입니다. 실험 결과가 나올 때마다 `현재 근거` 컬럼을 갱신하고, 갱신 이력은 git 히스토리로 남깁니다.

## 핵심 가설

> **서울 및 수도권에서 처음 독립하며 여러 매물을 직접 보는 20대는,
> 집에 관한 정보가 아예 없어서가 아니라 현장에서 무엇을 어떻게 확인하고 여러 집을 어떤 기준으로 비교해야 하는지 몰라 중요한 문제를 놓친다.
>
> 자취선배가 매물별 5분 상황형 체크리스트와 상태·메모 기록, 동일 기준 비교 기능을 제공하면 사용자는 실제 집보기 과정에서 이를 반복 사용하고, 기억과 감이 아닌 확인한 근거를 바탕으로 집을 선택할 것이다.**

## 하위 가설

| 가설 | 확인할 행동 | 현재 근거 |
| --- | --- | --- |
| 문제 가설 | 입주 후 발견한 문제가 집보기 때 확인 가능했고, 후보 정보가 기억·사진·메모에 흩어졌다고 말함 | 개인 경험과 초기 응답은 있으나 타겟 인터뷰 보강 필요 |
| 메시지 가설 | 손실 사례를 본 타겟이 체크 자료를 요청하거나 베타에 신청함 | [1차 랜딩 실험](../experiments/2026-08-landing.md)에서 검증 예정 |
| 현장 사용 가설 | 실제 임장에서 핵심 체크를 5분 안에 완료함 | 미검증 |
| 반복 사용 가설 | 같은 사용자가 두 번째 실제 매물에서도 다시 사용함 | 미검증(가장 중요한 가설) |
| 비교 가치 가설 | 2개 이상 매물 기록 후 비교 화면을 열고 추가 질문, 후보 제외, 재방문 등 행동이 달라짐 | 미검증 |
| 신뢰 가설 | 판정을 대신하지 않고 확인 방법, 공식 출처를 주는 방식을 신뢰함 | [주거지원 프로토타입](../learnings/pivot-history.md)에서 일부 간접 확인 |
| 포지셔닝 가설 | `플랫폼 중립, 임차인 우선`이 서비스 선택과 추천 이유가 됨 | 미검증 |

## 가장 위험하고 중요한 가정

가장 위험하고 중요한 가정은 `체크리스트가 필요하다고 말한다`가 아니라 다음입니다.

> **중개사가 옆에 있는 짧은 집보기 현장에서 사용하고, 다음 매물에서도 다시 사용하는가?**

이 가정은 [2차 실제 임장 MVP 실험](../experiments/2026-08-field-mvp.md)에서 검증합니다.
