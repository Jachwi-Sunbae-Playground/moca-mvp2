# 지도와 주변 분석 명세

- 상태: 구현 기준 v1
- 관련 화면: `13-1`, `13-2`, `13-3`, `02`

## 공급자 선택

MVP2 v1은 지도 표시와 장소 데이터의 일관성, 국내 주소 품질, 설정 수를 고려해 Kakao Maps로 통일합니다.

- 프론트엔드 지도: [Kakao Maps JavaScript SDK](https://apis.map.kakao.com/web/guide/)
- 백엔드 주소·장소: [Kakao Local REST API](https://developers.kakao.com/docs/ko/local/dev-guide)
- 계정·쿼터 주의: [Kakao Maps 이용 안내](https://developers.kakao.com/docs/ko/kakaomap/common)

REST API 키는 백엔드에만 두고 JavaScript 키는 등록 도메인 제한을 적용합니다. 2026년 7월 21일 이후 첫 번째 활성화 앱에만 무료 쿼터가 적용될 수 있으므로 유료 API나 비즈월렛을 자동으로 활성화하지 않습니다.

## 요구사항

- `REQ-MAP-001`: 지도 진입 시 브라우저 현재 위치를 요청하고 성공하면 중심으로 사용합니다.
- `REQ-MAP-002`: 권한 거부·타임아웃이면 최근 선택 위치 또는 서울 기본 중심을 사용하고 주소 검색 CTA를 제공합니다.
- `REQ-MAP-003`: 좌표가 있는 회원 매물을 핀으로 표시하고 선택하면 `13-3` 주변 분석으로 이동합니다.
- `REQ-MAP-004`: `13-2`에서 지도 중심 또는 탭한 위치를 역지오코딩해 도로명·지번 주소를 보여줍니다.
- `REQ-MAP-005`: 위치 확인 후 `02`에 주소와 좌표를 전달하고 사용자가 등록 전 수정할 수 있게 합니다.
- `REQ-MAP-006`: `13-3`은 전체·500m·1km·2km 반경 선택과 카테고리 필터를 제공합니다.
- `REQ-MAP-007`: 병원·교통·학교·편의점·중개업소의 장소·거리·좌표와 카테고리 개수를 제공합니다.

## 카테고리 매핑

| 제품 카테고리 | Kakao 조회 |
| --- | --- |
| 병원 | 카테고리 `HP8` |
| 교통 | 지하철 `SW8`와 키워드 `버스정류장`, ID 기준 중복 제거 |
| 학교 | 카테고리 `SC4` |
| 편의 | 편의점 `CS2` |
| 중개 | 부동산중개업소 `AG2` |

실시간 운행·도착 정보는 제공하지 않습니다.

## 정책

- `POL-MAP-001`: 좌표계는 WGS84, DB는 소수점 7자리까지 저장합니다.
- `POL-MAP-002`: 주변 시설 원본은 DB에 저장하지 않고 요청 시 조회합니다.
- `POL-MAP-003`: 반경은 500·1,000·2,000m만 허용합니다.
- `POL-MAP-004`: 백엔드는 중심 좌표를 소수점 4자리로 정규화한 키로 카테고리·반경별 결과를 10분 캐시합니다.
- `POL-MAP-005`: 공급자 전체 응답을 전달하지 않고 장소 ID·이름·카테고리·주소·좌표·거리만 정규화합니다.
- `POL-MAP-006`: 외부 호출은 짧은 연결·응답 타임아웃을 적용하고 429·5xx·타임아웃을 `MAP_PROVIDER_UNAVAILABLE`로 변환합니다.
- `POL-MAP-007`: 정확한 사용자 현재 좌표와 API 키를 일반 로그에 기록하지 않습니다.
- `POL-MAP-008`: 로컬 기본 `demo` 모드는 같은 계약의 고정 주소·장소 데이터를 반환합니다. `live` 모드에 키가 없으면 애플리케이션 시작에 실패합니다.
- `POL-MAP-009`: 좌표 없는 기존 매물은 지도 핀에서 제외하되 상세·수정에서 주소를 추가할 수 있습니다.
- `POL-MAP-010`: `전체`를 선택하면 반경을 최대 지원값 2km로 두고 카테고리 선택을 해제해 모든 카테고리를 표시합니다.

## 인수 기준

- 외부 키 없이도 세 지도 화면, 반경·카테고리 변경, 위치 선택과 매물 등록 흐름이 동작합니다.
- 실제 키를 넣으면 지도 타일·주소·장소가 실데이터로 바뀝니다.
- 권한 거부, 주소 없음, 장소 없음, 공급자 장애와 쿼터 초과가 빈 화면이나 무한 로딩으로 끝나지 않습니다.
- 다른 회원의 매물 좌표는 지도 API 응답에 포함되지 않습니다.
