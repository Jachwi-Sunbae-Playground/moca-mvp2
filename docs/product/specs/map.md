# 지도와 주변 분석 명세

- 상태: 구현 기준 v1
- 관련 화면: `13-1`, `13-2`, `13-3`, `02`

## 공급자 선택

MVP2 v1은 지도 표시·주소·일반 장소를 Kakao Maps로 통일합니다. Kakao Local API가 일반 버스정류소 위치를 제공하지 않으므로 실제 버스정류소는 선택적으로 국토교통부 TAGO 버스정류소정보를 합쳐 제공합니다.

- 프론트엔드 지도: [Kakao Maps JavaScript SDK](https://apis.map.kakao.com/web/guide/)
- 백엔드 주소·장소: [Kakao Local REST API](https://developers.kakao.com/docs/ko/local/dev-guide)
- 백엔드 버스정류소: [국토교통부 TAGO 버스정류소정보](https://www.data.go.kr/data/15098534/openapi.do)
- 계정·쿼터 주의: [Kakao Maps 이용 안내](https://developers.kakao.com/docs/ko/kakaomap/common)

REST API 키는 백엔드에만 두고 JavaScript 키는 등록 도메인 제한을 적용합니다. 2026년 7월 21일 이후 첫 번째 활성화 앱에만 무료 쿼터가 적용될 수 있으므로 유료 API나 비즈월렛을 자동으로 활성화하지 않습니다.

## 요구사항

- `REQ-MAP-001`: 지도 진입 시 브라우저 현재 위치를 요청하고 성공하면 중심으로 사용합니다.
- `REQ-MAP-002`: 권한 거부·타임아웃이면 최근 선택 위치 또는 서울 기본 중심을 사용하고 주소 검색 CTA를 제공합니다.
- `REQ-MAP-003`: 좌표가 있는 회원 매물을 핀으로 표시하고 선택하면 `13-3` 주변 분석으로 이동합니다.
- `REQ-MAP-004`: `13-2`에서 지도 중심 또는 탭한 위치를 역지오코딩해 도로명·지번 주소를 보여줍니다.
- `REQ-MAP-005`: 위치 확인 후 `02`에 주소와 좌표를 전달하고 사용자가 등록 전 수정할 수 있게 합니다.
- `REQ-MAP-006`: `13-1`과 `13-3`은 전체·500m·1km·2km 반경 선택과 카테고리 필터를 제공합니다.
- `REQ-MAP-007`: 병원·교통·학교·편의점·중개업소의 장소·거리·좌표와 카테고리 개수를 제공합니다.
- `REQ-MAP-008`: `13-1`과 신규 등록의 `13-2`는 현재 위치를 먼저 사용하고, 매물 수정에서 연 `13-2`는 저장된 매물 위치를 먼저 사용합니다.
- `REQ-MAP-009`: 카테고리는 여러 개를 동시에 켜고 끌 수 있으며 매물 핀과 현재 위치 핀은 시설 필터와 관계없이 유지합니다.
- `REQ-MAP-010`: `13-1`과 `13-3`은 공급자가 반환한 시설의 실제 좌표를 표시하고, 가까운 시설은 축소 단계에서만 군집 수로 묶었다가 확대하면 개별 핀으로 표시합니다.
- `REQ-MAP-011`: 주소 검색은 지도를 가리지 않도록 기본으로 접어 두고 검색 버튼을 누르거나 현재 위치 조회가 실패했을 때 엽니다.
- `REQ-MAP-012`: 사용자가 직접 바꾼 지도 확대 단계는 중심 좌표 상태가 갱신되어도 유지합니다.
- `REQ-MAP-013`: `13-1`과 `13-3`의 시설 카테고리는 기본으로 모두 끄고, 요약 시트의 카테고리 개수는 항상 보여줍니다.
- `REQ-MAP-014`: `13-1`과 `13-3`은 선택한 카테고리만 핀과 목록에 반영하고, 펼친 목록은 모바일 화면 높이 안에서 터치·키보드로 독립 스크롤합니다.
- `REQ-MAP-015`: 개별 시설 핀을 누르면 목록과 같은 이름·거리·주소를 지도 위 상세 카드로 보여주고, 군집 핀을 누르면 해당 위치를 중심으로 한 단계 확대합니다.
- `REQ-MAP-016`: 시설 핀과 우측 카테고리 필터는 병원·교통·학교·편의·중개를 구분하는 같은 아이콘을 사용하고, 시설 카테고리별 색상은 유지합니다.

## 카테고리 매핑

| 제품 카테고리 | Kakao 조회 |
| --- | --- |
| 병원 | 카테고리 `HP8` |
| 교통 | Kakao 지하철 `SW8` + TAGO 중심 500m 실제 버스정류소(설정 시), 공급자 ID 기준 중복 제거 |
| 학교 | 카테고리 `SC4` |
| 편의 | 편의점 `CS2` |
| 중개 | 부동산중개업소 `AG2` |

실시간 운행·도착 정보는 제공하지 않습니다.

## 정책

- `POL-MAP-001`: 좌표계는 WGS84, DB는 소수점 7자리까지 저장합니다.
- `POL-MAP-002`: 주변 시설 원본은 DB에 저장하지 않고 요청 시 조회합니다.
- `POL-MAP-003`: 반경은 500·1,000·2,000m만 허용합니다.
- `POL-MAP-004`: 백엔드는 중심 좌표를 소수점 4자리로 정규화한 키로 카테고리·반경별 결과를 10분 캐시합니다.
- `POL-MAP-005`: 공급자 전체 응답을 전달하지 않고 장소 ID·이름·카테고리·주소·좌표·거리만 정규화합니다.
- `POL-MAP-006`: 외부 호출은 짧은 연결·응답 타임아웃을 적용하고 429·5xx·타임아웃을 `MAP_PROVIDER_UNAVAILABLE`로 변환합니다.
- `POL-MAP-007`: 정확한 사용자 현재 좌표와 API 키를 일반 로그에 기록하지 않습니다.
- `POL-MAP-008`: 로컬 기본 `demo` 모드는 같은 계약의 고정 주소·장소 데이터를 반환합니다. `live` 모드에 키가 없으면 애플리케이션 시작에 실패합니다.
- `POL-MAP-009`: 좌표 없는 기존 매물은 지도 핀에서 제외하되 상세·수정에서 주소를 추가할 수 있습니다.
- `POL-MAP-010`: `전체`를 선택하면 반경을 최대 지원값 2km로 두고 다섯 카테고리를 모두 선택합니다.
- `POL-MAP-011`: 사용자가 마지막으로 본 지도 중심은 브라우저 세션에만 저장하며 현재 위치 조회 실패 시 대체 중심으로 사용합니다.
- `POL-MAP-012`: 시설 핀과 군집은 같은 실제 장소 목록으로 만들며, 군집 좌표는 포함 장소 좌표의 중심으로 계산합니다. 지도 확대 단계 3 이하에서는 군집 없이 개별 시설을 표시합니다.
- `POL-MAP-013`: Kakao 장소 검색은 페이지당 15개씩 `is_end`까지 최대 세 페이지를 조회합니다. 카테고리 검색 하나당 최대 45개를 정규화합니다.
- `POL-MAP-014`: `13-1`의 조회 반경 중심은 브라우저 현재 위치 또는 주소로 선택한 위치로 고정합니다. 지도 이동은 화면 중심만 바꾸고, 반경 선택은 조회 중심으로 돌아와 해당 범위를 보여줍니다.
- `POL-MAP-015`: `BUS_STOP_PROVIDER=tago`일 때 TAGO가 정의한 조회 중심 500m 안의 실제 버스정류소를 지하철 결과에 합칩니다. 지도의 1km·2km 반경에서도 가장 가까운 500m 정류소를 함께 표시하며, TAGO 장애 시 지하철과 다른 시설은 계속 제공합니다.
- `POL-MAP-016`: `전체`는 반경 2km와 다섯 카테고리를 모두 켜는 명시적 동작입니다. 화면 초기 진입에서는 2km 반경만 선택하고 시설 카테고리는 모두 끅니다.

- `POL-MAP-017`: Kakao 바탕지도에 렌더링된 버스정류소 등의 POI는 앱이 조회할 수 있는 장소 결과로 취급하지 않습니다. 시설 개수·핀·상세의 정본은 백엔드가 정규화해 반환한 Kakao Local·TAGO 결과입니다.

## 인수 기준

- 외부 키 없이도 세 지도 화면, 반경·카테고리 변경, 위치 선택과 매물 등록 흐름이 동작합니다.
- Kakao 키를 넣으면 지도 타일·주소·일반 장소가 실데이터로 바뀌고, TAGO 설정과 공공데이터포털 키를 넣으면 중심 500m 실제 버스정류소가 추가됩니다.
- 권한 거부, 주소 없음, 장소 없음, 공급자 장애와 쿼터 초과가 빈 화면이나 무한 로딩으로 끝나지 않습니다.
- 다른 회원의 매물 좌표는 지도 API 응답에 포함되지 않습니다.
- 모바일 화면에서 카테고리를 두 개 이상 선택할 수 있고, 지도 군집·개별 핀·펼친 실제 목록이 같은 장소 결과를 사용합니다.
- 지도 확대·축소 후 중심 좌표가 갱신되어도 확대 단계가 기본값으로 되돌아가지 않습니다.
- 초기 진입에서 시설 핀은 보이지 않지만 요약 시트에서 모든 카테고리의 수를 확인하고 선택한 시설만 핀·목록으로 탐색할 수 있습니다.
- 펼친 시설 목록은 모바일 화면을 벗어나지 않고 스와이프·터치 스크롤로 끝까지 확인할 수 있습니다.
- 개별 시설 핀을 누르면 같은 시설의 카테고리·이름·거리·주소를 확인할 수 있고, 핀과 우측 필터의 카테고리 아이콘이 일치합니다.
- 군집 핀을 누르면 군집 중심으로 확대되어 포함된 개별 시설을 탐색할 수 있습니다.
- `13-3` 하단 요약은 매물명을 작은 보조 문구로 중복 표시하지 않고 `{매물명} 매물 주변 {반경}` 제목으로 보여줍니다.
