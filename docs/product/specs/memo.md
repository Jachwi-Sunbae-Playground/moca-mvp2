# 매물 메모 명세

- 상태: 구현 기준 v1
- 관련 화면: `03`, `03-2`

## 요구사항

- `REQ-MEMO-001`: 매물마다 구조화된 기본 메모 양식과 자유 메모 하나를 제공합니다.
- `REQ-MEMO-002`: 처음 진입하면 활성 시스템 메모 항목을 당시 순서와 이름으로 초기화합니다.
- `REQ-MEMO-003`: 전체 양식과 자유 메모를 한 번에 저장하고 상세에는 요약을 표시합니다.

## 기본 양식

MVP2의 기본 시스템 메모 항목은 다음 순서입니다.

1. 입주 가능일
2. 방 옵션
3. 관리비 및 공과금
4. 방문 일정

MVP1에서 이미 생성된 스냅샷은 자동 변경하지 않습니다.

## 정책

- `POL-MEMO-001`: 매물당 메모 루트는 최대 하나입니다.
- `POL-MEMO-002`: 구조화 항목은 최대 20개, 각 내용은 100자, 자유 메모는 2,000자입니다.
- `POL-MEMO-003`: 저장 요청은 기존 항목 ID의 내용과 자유 메모를 전체 교체하며 누락된 활성 스냅샷을 임의 삭제하지 않습니다.
- `POL-MEMO-004`: 저장 성공은 매물 최근 활동 시각을 갱신합니다.

## 인수 기준

- 저장 후 재진입하면 동일 값과 순서가 표시됩니다.
- 다른 매물이나 다른 회원의 메모 항목 ID로 저장할 수 없습니다.
- 저장 실패 시 입력값을 유지하고 재시도할 수 있습니다.
