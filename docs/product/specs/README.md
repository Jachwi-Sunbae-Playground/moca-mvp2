# MVP2 기능 명세

| 명세 | 책임 |
| --- | --- |

| [매물](property.md) | 매물 CRUD, 주소, 정렬과 비교표 |
| [사진](photo.md) | 업로드, 대표 사진과 객체 정합성 |

| [체크리스트](checklist.md) | 시스템·사용자·매물 적용 체크리스트 |

요구사항 ID는 `REQ-<도메인>-NNN`, 정책 ID는 `POL-<도메인>-NNN`을 사용합니다. 구현 중 정책이 바뀌면 관련 명세와 결정 대장을 같은 PR에서 고칩니다.
