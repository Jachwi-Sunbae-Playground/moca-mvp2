# 인증 명세

- 상태: 구현 기준 v1
- 관련 화면: `00`, `10`

## 요구사항

- `REQ-AUTH-001`: 운영 사용자는 Google OAuth로 로그인합니다.
- `REQ-AUTH-002`: 최초 로그인은 회원을 만들고 재로그인은 이메일이 같은 회원 데이터를 이어서 보여줍니다.
- `REQ-AUTH-003`: 로컬 `demo` 모드는 외부 키 없이 고정 데모 회원으로 로그인합니다.
- `REQ-AUTH-004`: 로그인 후 매물 목록으로 이동하고 마이페이지에서 이름·이메일·연동 방식을 확인합니다.
- `REQ-AUTH-005`: 로그아웃하면 token과 개인 query cache를 제거하고 로그인 화면으로 이동합니다.
- `REQ-AUTH-006`: 인증되지 않은 보호 API는 401, 다른 회원의 자원은 404로 처리합니다.

## 정책

- `POL-AUTH-001`: 기본 access token 유효 시간은 12시간입니다.
- `POL-AUTH-002`: MVP2 v1은 refresh token을 도입하지 않습니다.
- `POL-AUTH-003`: 브라우저 새로고침 복구를 위해 `sessionStorage`에 access token과 만료 시각을 보관합니다. 브라우저 종료 뒤에는 다시 로그인합니다.
- `POL-AUTH-004`: 데모 로그인은 `local` 프로필과 명시적인 `AUTH_MODE=demo`에서만 허용하며 운영 시작에 실패하도록 방어합니다.
- `POL-AUTH-005`: 토큰·authorization code·Google secret·회원 이메일을 일반 로그에 기록하지 않습니다.
- `POL-AUTH-006`: `demo` 모드에서는 `00`의 주 버튼을 `데모로 시작하기`, Google 모드에서는 `구글로 로그인하기`로 표시합니다.

## 인수 기준

- Google 설정이 없더라도 로컬에서 로그인 화면과 전체 개인 기능을 체험할 수 있습니다.
- Google 설정이 있으면 authorization code 교환과 기존 회원 재로그인이 성공합니다.
- 새로고침 뒤 같은 탭에서 세션을 복구하고 만료·401·로그아웃 뒤에는 보호 화면에 접근할 수 없습니다.
