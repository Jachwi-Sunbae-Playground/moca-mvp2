# 자취선배 개요

## 한 문장으로 설명하는 자취선배

> **집은 매물 앱에서 찾고, 결정은 자취선배에서.**

자취선배는 매물을 직접 중개하거나 집의 품질을 대신 판정하지 않습니다. 사용자가 여러 플랫폼에서 찾은 후보를 한곳에 모으고, 방문 전·집보는 현장·계약 직전에 무엇을 확인할지 알려주며, 사용자가 직접 확인한 상태와 메모를 매물별로 기록하고 비교하도록 돕는 **임차인 전용 집 선택 도구**입니다.

### 현재 제품 범위

```
매물 후보 저장
→ 방문 전 온라인·전화 확인
→ 현장에서 생활 조건·하자 확인
→ 후보별 기준 비교
→ 계약 직전 권리·서류·특약 확인
```

### 하지 않는 일

- 좋은 집인지 나쁜 집인지 대신 판정하지 않습니다.
- 법적으로 안전한 계약이라고 보증하지 않습니다.
- 주거지원 대상 여부를 확정하지 않습니다.
- 사용자의 비공개 기록을 공개 리뷰로 전환하지 않습니다.

자취선배는 **판정 대신 질문을 제공하고, 단정 대신 확인 상태와 공식 출처를 남기며, 최종 결정은 사용자에게 돌려주는 서비스**를 지향합니다.

## 장기 방향과 현재 범위의 경계

자취선배는 체크리스트 하나로 끝나는 서비스보다 자취 생애주기를 함께하는 서비스를 지향합니다.

```
집 찾기
→ 확인 및 비교
→ 계약
→ 입주 준비
→ 생활 중 문제 해결
→ 재계약 및 퇴거
→ 다음 집 찾기
```

다만 현재 장기 방향을 검증된 수요처럼 다루지 않습니다. 우선 `집을 직접 보는 순간`에서 반복 사용을 확인하고, 그 기록이 다음 단계로 자연스럽게 이어질 때만 확장합니다.

수익은 현재 목표가 아닙니다. 향후 사용자가 100명 이상 모이고 실제 가치가 확인되면 다음 가설을 별도로 검증할 수 있습니다.

- 매물 3개까지 무료, 이후 한 번의 이사 동안(약 한 달) 무제한으로 사용하는 5,000원 안팎의 이사 패스
- 목적은 매출 극대화가 아니라 사용자가 실제 가치를 느껴 작은 금액이라도 지불하는지 확인하는 것

입주 사진의 장기 보관과 이사·청소·인터넷 제휴는 책임과 이해충돌 가능성이 크므로 현재 범위에서는 제외합니다.
