# MVP2 사용자 흐름

- 문서 성격: 파생
- 대조 대상: [MVP2 와이어프레임](../../design/wireframes/README.md), [기능 명세](../specs/README.md)

## 공통 진입

1. 비로그인 사용자는 `00`에서 제품 설명을 확인합니다.
2. 닉네임과 선택 비밀번호로 시작하면 `01`로 이동합니다.
3. 보호 화면에서 세션이 없거나 만료되면 원래 경로를 보존하고 `00`으로 이동합니다.
4. 로그아웃하면 개인 cache를 비우고 `00`으로 이동합니다.

처음 쓰는 닉네임은 입력한 비밀번호 유무에 따라 보호 또는 공유 닉네임으로 만들어집니다. 이미 존재하는 보호 닉네임은 비밀번호가 맞아야 하고, 공유 닉네임은 비밀번호 없이 같은 기록을 이어서 사용합니다. 세부 정책은 [인증 명세](../specs/authentication.md)를 따릅니다.

## 매물 흐름

### 생성

`01 → 02 → 03`

- `01`의 추가 버튼은 빈 매물 입력 상태의 `02`로 이동합니다.
- `02`의 주소 입력은 검색 결과를 선택하거나 `13-2`에서 돌아올 수 있습니다.
- 생성 성공 시 새 매물의 `03`으로 이동하고 실패하면 입력을 유지합니다.

### 조회·수정·삭제

- `01 → 03`: 매물 카드 선택
- `03 → 03-3 → 03`: 전체 수정 후 복귀
- `03`에서 삭제 확인 후 성공하면 `01`, 취소·실패하면 `03`을 유지
- `01 → 매물 비교`: 비교표 받기에서 매물 2~5개를 선택합니다.
- 선택 완료 후 비교 PDF를 내려받습니다. PDF는 첫 장에 핵심 사실을 나란히 두고, 이후 매물별 기본 정보·사진·메모·체크 기록 전체를 이어서 보여줍니다.

### 사진과 메모

- `03 → 03-1 → 03`: 사진 추가·대표 지정·삭제 후 복귀
- `03 → 03-2 → 03`: 메모 저장 후 복귀
- 업로드·메모 저장 실패는 현재 입력과 화면을 유지하고 항목별 재시도를 제공합니다.

## 매물 체크 흐름

`03 → 04 → 05 → 03`

1. `03`에서 단계를 선택하면 적용 여부와 관계없이 `04`로 이동합니다.
2. `04`에서 내 체크리스트 또는 기본체크리스트 하나를 선택합니다. 이미 적용된 목록이 있으면 현재 선택으로 표시합니다.
3. 선택 완료는 신규 적용 또는 교체 확인 뒤 `05`로 이동합니다.
4. `05`는 같은 매물 안에서 세 단계 탭을 전환합니다.
5. 상태와 메모는 자동 저장하고 뒤로 가면 `03`으로 복귀합니다.

## 체크리스트 관리 흐름

`03 또는 하단 탭 → 06 → 07 → 08 → 09`

- `06`의 단계 카드는 해당 단계의 `07`로 이동합니다.
- `07`과 `04`의 새 체크리스트 만들기는 시작 방식 선택 없이 `08`로 바로 이동하고 해당 단계의 `CORE`를 불러옵니다. `OPTIONAL`은 `09`에서 선택하며 생성 초깃값은 [`POL-CHECK-006`](../specs/checklist.md#정책)을 따릅니다.
- `07`의 기존 체크리스트 편집은 `08`로 이동합니다.
- `08`의 항목 추가는 현재 편집 상태를 보존한 채 `09`로 이동합니다.
- `09`에서 제공 `OPTIONAL`을 여러 개 선택하거나 자신의 질문을 직접 입력해 추가하면 `08`로 돌아옵니다.
- `08` 저장 성공은 진입 출처가 `04`면 `04`, 그 외에는 `07`로 돌아갑니다.
- `07` 삭제는 확인 뒤 목록에 머뭅니다.

## 지도 흐름

### 지도 탐색

`01 → 13-1`

- 위치 권한 성공: 현재 좌표로 이동합니다.
- 권한 거부·GPS 비활성·타임아웃: 안내와 주소 검색·기본 중심을 제공합니다.
- 주소 검색은 기본으로 접혀 있고 검색 버튼을 누르거나 현재 위치 조회에 실패하면 열립니다.
- 전체·500m·1km·2km는 현재 위치 또는 주소로 선택한 위치를 기준으로 조회하고, 지도 이동은 조회 기준을 바꾸지 않습니다.
- 초기에는 시설 카테고리를 모두 끄고 하단 요약에서 반경별 개수만 보여줍니다. 카테고리를 하나 이상 선택하면 선택한 실제 시설만 작은 핀과 목록에 반영하며, 축소하면 가까운 시설이 군집 수로 보이고 확대하면 개별 핀으로 나뉩니다.
- 개별 시설 핀을 누르면 목록과 같은 카테고리·이름·거리·주소가 지도 위에 표시됩니다. 군집 핀을 누르면 해당 위치를 중심으로 한 단계 확대합니다.
- 하단 시설 목록은 모바일 화면 안에서 독립적으로 스크롤합니다.
- 기존 매물 핀 선택은 `13-3`으로 이동합니다.

### 지도에서 매물 등록

`13-1 → 13-2 → 02 → 03`

1. `13-1`의 매물 추가 버튼이 `13-2`로 이동합니다.
2. 신규 등록이면 현재 위치를 먼저 표시하고, 매물 수정에서 열면 저장된 매물 위치를 먼저 표시합니다.
3. 지도 이동·탭은 후보 좌표를 바꾸고 역지오코딩 결과를 보여줍니다.
4. 주소 확인 후 `02`로 좌표와 주소를 전달합니다.
5. 사용자가 나머지 정보를 입력하고 생성하면 `03`으로 이동합니다.

### 주변 분석

`13-1 → 13-3`

- 선택한 매물을 중심으로 500m·1km·2km를 전환합니다.
- 하단 요약 제목에는 매물명과 현재 반경을 함께 표시하며 세부 표기는 [지도 기능 명세](../specs/map.md)의 인수 기준을 따릅니다.
- 초기에는 시설 카테고리를 모두 끄고 하단 요약에서 반경별 개수만 보여줍니다. 여러 카테고리를 함께 선택하면 선택한 실제 시설 좌표만 표시하며, 축소하면 가까운 시설만 좌표 중심 군집으로 묶습니다.
- 개별 시설 핀을 누르면 목록과 같은 카테고리·이름·거리·주소가 지도 위에 표시됩니다. 군집 핀을 누르면 해당 위치를 중심으로 한 단계 확대합니다.
- 실제 시설 이름·거리·주소 목록은 하단 요약을 펼쳤을 때 선택 카테고리만 표시하고 모바일 화면 안에서 독립적으로 스크롤합니다.
- 장소가 없으면 0개 빈 상태, 공급자 장애면 재시도 상태를 표시합니다.
- 뒤로 가면 마지막으로 본 지도 중심을 복원한 `13-1`로 돌아갑니다.
