# 2026-08 2차 실험: 실제 임장 MVP 검증

- 상태: 설계
- 관련 가설: [현장 사용·반복 사용·비교 가치·행동 변화 가설](../product/hypotheses.md)
- 문서 성격: 시점 고정
- 갱신 정책: 실험 종료 후 결과와 판정을 추가하되, 기록한 관찰과 판단은 고치지 않는다

## 검증할 핵심 행동

```
실제 매물 저장
→ 방문 전 체크
→ 현장에서 5분 핵심 체크
→ 두 번째 실제 매물에서도 반복 사용
→ 비교 화면 확인
→ 질문·재방문·후보 제외·계약 판단 중 하나에 활용
```

## 모집 방식

온라인과 오프라인 중 하나를 선택하기보다 역할을 나눕니다.

1. 온라인 광고·커뮤니티·지인 수소문으로 넓게 모집합니다.
2. 짧은 선별 폼에서 실제 매물 링크와 방문 예정일을 받습니다.
3. 조건에 맞는 사람과 10분 사전 통화를 해 일정과 테스트 방식을 맞춥니다.
4. 현장에서는 가능한 경우 동행 관찰하고, 어려우면 화면 기록·행동 로그·즉시 음성 메모를 받습니다.
5. 각 매물 확인 직후 3분 기록, 두 번째 매물 이후 비교, 최종 선택 후 15분 인터뷰를 진행합니다.

이 구조는 온라인 모집의 효율과 오프라인 관찰의 깊이를 분리해 가져갑니다.

## 최소 표본 초안

- 실제 사용자 6명
- 사용자당 실제 매물 3개 이상
- 최소 18회의 실제 집보기 세션
- 가능하면 첫 독립·경험자, 월세·전세, 동행 관찰·비동행 기록을 구분해 해석

표본이 작기 때문에 통계적 일반화보다 **실패 장면과 반복 사용 여부를 직접 관찰하는 것**을 목표로 합니다.

## 행동 판정 기준 초안

| 가설 | 잠정 채택 신호 | 기각·수정 신호 |
| --- | --- | --- |
| 현장 사용 | 6명 중 4명 이상이 5분 핵심 경로 완료, 완료시간 중앙값 5분 이하 | 절반 이상이 현장에서 앱을 열지 않거나 입력을 중단 |
| 반복 사용 | 6명 중 4명 이상이 두 번째 실제 매물에서도 다시 사용 | 첫 사용 후 필요성을 느껴도 두 번째 현장에서 사용하지 않음 |
| 비교 가치 | 6명 중 4명 이상이 2개 매물 비교 화면까지 도달 | 기록은 하지만 비교 화면을 열지 않거나 기억, 사진만으로 결정 |
| 행동 변화 | 6명 중 3명 이상에게 새로운 질문, 추가 확인, 재방문, 후보 제외, 특약 요청 중 하나가 발생 | 만족도는 높지만 실제 질문과 결정이 달라지지 않음 |
| 부담 수준 | 사용자가 중개사 앞에서도 대부분 탭과 짧은 메모로 완료 | 긴 설명, 입력 때문에 집을 보는 행위 자체를 방해 |

여기서 `새로운 위험을 몇 개 발견했는가`는 모든 좋은 집에서 반드시 발생하지 않습니다. 따라서 위험 발견 수만 보지 않고 다음을 함께 봅니다.

- 확인하지 못한 항목을 명확히 인식했는가
- 중개사에게 구체적인 질문이 생겼는가
- 매물별 차이를 설명할 수 있는가
- 최종 선택의 이유에 기록이 사용됐는가

## 핵심 지표

> **2개 이상의 실제 매물에서 현장 체크를 완료하고 비교까지 진행한 이사 프로젝트 수**

일반 서비스의 DAU나 30일 리텐션보다 한 번의 이사 프로젝트 안에서 반복 사용했는지를 우선합니다.
