# 프로젝트 문서

코드와 함께 변경되어야 하는 최종 합의 내용은 이 디렉터리에서 버전 관리한다.

| 디렉터리 | 내용 |
| --- | --- |
| `development` | 개발 환경, 실행 방법, 문제 해결 |
| `requirements` | 제품과 기술 요구사항 |
| `adr` | 기술적 판단과 근거, 대안, 트레이드오프 |
| `deployment` | 배포와 운영 가이드 |
| `conventions` | 팀 개발 컨벤션 |

실제 문서가 생길 때만 디렉터리를 생성한다. 파일명은 영문 `kebab-case` 형식을 기본으로 사용한다.
