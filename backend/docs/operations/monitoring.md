# 모니터링

- 상태: 로컬 기준, 공개 환경 없음
- 문서 성격: 파생
- 대조 대상: Actuator 설정, 향후 단일 EC2 구성
- 현재 제공 항목: Actuator health
- 외부 모니터링·알림 도구: 첫 배포 Issue에서 확정

## 관찰 대상

- 가용성: health 상태와 요청 성공 여부
- 오류: 애플리케이션 기동 실패와 HTTP 5xx
- 성능: 요청 지연시간
- 자원: CPU와 메모리
- 저장소: EBS 사용량과 MySQL 백업 성공 여부

## 원칙

- 알림은 담당자가 행동할 수 있는 조건에만 설정한다.
- 로그에 비밀번호, 토큰, 개인정보와 전체 요청·응답 본문을 남기지 않는다.
- 관찰하려는 질문과 판단 기준을 수집 전에 정한다.
- 사실로 관찰한 값과 팀의 해석을 구분해 기록한다.

도구를 선택할 때 보존 기간, 비용, 접근 권한과 알림 채널을 함께 결정한다.

첫 배포에서는 Actuator 내부 health, systemd·Caddy·Docker 로그와 AWS 기본 EC2 지표로 시작한다. 외부 사용자를 받기 전 공개 HTTPS 상태 확인과 MySQL 백업 실패 알림의 수신 경로를 정한다. 현재는 배포하지 않았으므로 운영 알림이 존재한다고 가정하지 않는다.
