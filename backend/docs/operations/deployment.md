# 배포

- 상태: 미정
- 현재 배포 환경: 없음

배포 대상과 플랫폼을 선택하면 다음 내용을 기록한다.

- 배포 환경과 접근 가능한 URL
- 플랫폼 선택 이유, 검토한 대안과 한계
- 빌드 산출물과 배포 명령 또는 파이프라인
- 환경변수와 비밀 관리 방식
- 데이터베이스 연결과 마이그레이션 절차
- 배포 전 CI 조건과 배포 후 health·smoke test
- 담당자와 실패 시 중단 기준

배포 결과와 사용자 관찰은 [지정 요구사항 2](../requirements/02-deploy-and-observe.md)에 증거와 함께 기록한다.
