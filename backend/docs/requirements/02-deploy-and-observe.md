# 지정 요구사항 2: 사용자가 접근할 수 있게 배포하고 반응을 관찰한다

- 상태: 시작 전
- 현재 판단: 배포 대상 기능과 관찰 질문이 정해진 뒤 실행한다.
- 문서 성격: 시점 고정
- 갱신 정책: 진행에 따라 결과를 추가하되, 이미 기록한 사실과 그때의 판단은 고치지 않는다

## 1. 목적

외부 사용자가 접근할 수 있는 제품 또는 핵심 기능을 배포하고, 사용자의 반응을 근거로 유지·개선·피벗 중 다음 행동을 결정한다.

## 2. 완료 기준

- [ ] 외부 사용자가 접근할 수 있는 제품 또는 핵심 기능이 있다.
- [ ] 무엇을 확인하려는지 질문과 판단 기준을 배포 전에 정했다.
- [ ] 사용자 인터뷰, 사용성 테스트, 행동 기록 또는 로그로 근거를 수집했다.
- [ ] 관찰한 사실과 팀의 해석을 구분해 기록했다.
- [ ] 결과가 실제 다음 행동으로 이어졌다.

## 3. 수행 기록

| 항목 | 기록 |
| --- | --- |
| 접근 가능한 링크 | 미정 |
| 확인하려는 질문 | 미정 |
| 판단 기준 | 미정 |
| 관찰 방법 | 미정 |
| 수집한 사실 | 미정 |
| 팀의 해석 | 미정 |
| 다음 행동 | 미정 |

## 4. 제출 내용

- 접근 가능한 제품 또는 핵심 기능 링크
- 확인하려던 질문과 판단 기준
- 사용한 관찰 방법과 수집한 근거
- 관찰 결과, 해석과 다음 행동
- 배포·관찰 방식의 선택 근거와 한계
